B1 — SISTEMA DE PERFIL INCOMPLETO (NOTIFICACIÓN/MODAL)
───────────────────────────────────────────────────────

Crear componente: resources/js/Components/PerfilIncompleto.vue

Para el COMPRADOR:
Calcular porcentaje de completitud del perfil según campos:
  name (20%) + telefono (20%) + sector/necesidades (20%) + foto (20%) + empresa (20%)

Para el PROVEEDOR:
  nombre_restaurante (15%) + descripcion (15%) + telefono (10%) + rfc (10%)
  + municipio (10%) + sitio_web (10%) + logo (10%) + al menos 1 producto (20%)

DISEÑO DEL BANNER (no modal intrusivo — aparece en el dashboard):
  - Banner pegado en la parte superior del contenido (debajo del navbar)
  - Barra de progreso visual con porcentaje
  - Mensaje: "Tu perfil está al [X]% — complétalo para que los [compradores/proveedores]
    te encuentren fácilmente"
  - Botón "Completar perfil" que abre el modal de edición existente
  - Botón X para cerrarlo (se guarda en localStorage que fue cerrado)
  - Si el perfil está al 100%, el banner desaparece permanentemente
  - El banner solo aparece si el perfil está por debajo del 80%
  - Diseño: usando colores guinda, responsivo para móvil (ocupa todo el ancho)
  - En móvil: compacto con solo la barra de progreso y el botón

LÓGICA DE PERSISTENCIA:
  - Usar localStorage key: 'perfil_banner_cerrado_{user_id}'
  - Si el usuario cierra el banner, no volver a mostrarlo en 24 horas
  - Pasadas las 24 horas, si sigue incompleto, volver a mostrar

DATOS DESDE EL BACKEND:
  En HandleInertiaRequests.php, añadir a los datos compartidos:
    'perfil_completitud' => [
        'porcentaje' => $porcentaje,  // 0-100
        'campos_faltantes' => [...],  // lista de campos que faltan
    ]

2. Subir archivos al servidor vía Git (SSH):
   cd /home/usuario/impulsate
   git add .
   git commit -m "feat: mejoras paneles comprador y proveedor — [lista de cambios]"

   node_modules/, .env, storage/logs/*.log

   cd /home/usuario/impulsate
   composer install --no-dev --optimize-autoloader
   php artisan migrate --force
   php artisan optimize:clear
   php artisan config:cache
   php artisan route:cache
   php artisan view:cache

4. Copiar assets compilados:
   Copiar public/build/ → public_html/build/

5. Verificación post-deploy:
   php artisan about
   # Revisar: tail -20 storage/logs/laravel.log
   # Visitar: https://lightcyan-mallard-509513.hostingersite.com/
