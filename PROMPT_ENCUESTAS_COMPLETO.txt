BUG CRÍTICO 2 — Métricas no funcionan al responder
════════════════════════════════════════════════════════════════════════════════

En EncuestaController::store(), el loop guarda respuestas usando $pregunta['id']
como clave del request. Verifica que la vista Encuestas/Responder.vue envía
exactamente $pregunta['id'] como name del input.

Si las métricas de tipo 'escala' no suman bien, es porque el campo respuesta
en encuesta_respuestas es VARCHAR. La query usa CAST(respuesta AS DECIMAL).
En MySQL esto funciona si el valor es numérico. Verifica que el frontend
envía el valor numérico (no el label "⭐⭐⭐").

Asegúrate de que EncuestaController::store() guarda el tipo de pregunta
correctamente en encuesta_respuestas.tipo para que las métricas puedan
agrupar por tipo.

  - opciones  → radio buttons (una sola opción)

    public function enviarParaEvento(Request $request)
    {
        $request->validate([
            'evento_id'    => 'required|exists:eventos,id',
            'plantilla_id' => 'nullable|exists:encuesta_plantillas,id',
            'segmento'     => 'required|in:todos,proveedores,compradores,proveedores_evento,compradores_evento',
        ]);

        $evento    = Evento::findOrFail($request->evento_id);
        $plantilla = $request->plantilla_id
            ? EncuestaPlantilla::find($request->plantilla_id)
            : EncuestaPlantilla::where('activa', true)->first();

        if (!$plantilla) {
            return back()->withErrors(['error' => 'No hay plantilla activa. Activa una plantilla primero.']);
        }

        $enviados = app(EncuestaEnvioService::class)
            ->enviarParaEvento($evento, $plantilla, $request->segmento);

        return back()->with('success', "Encuestas enviadas a {$enviados} participante(s).");
    }

Reemplaza el método enviarParaEvento():

    public function enviarParaEvento(
        Evento $evento,
        EncuestaPlantilla $plantilla,
        string $segmento = 'todos'
    ): int {
        // Construir query base según segmento
        $query = DB::table('evento_usuario')
            ->where('evento_id', $evento->id)
            ->where('estado', 'aprobado');

        match ($segmento) {
            'proveedores'         => $query->where('tipo', 'proveedor'),
            'compradores'         => $query->where('tipo', 'comprador'),
            'proveedores_evento'  => $query->where('tipo', 'proveedor'),
            'compradores_evento'  => $query->where('tipo', 'comprador'),
            default               => null, // 'todos' — sin filtro adicional
        };

        $participantes = $query->get();

        $enviados = 0;
        foreach ($participantes as $p) {
            // No enviar duplicado (mismo evento + usuario + plantilla + tipo)
            $existe = EncuestaSatisfaccion::where('evento_id', $evento->id)
                ->where('user_id', $p->user_id)
                ->where('tipo', $p->tipo)
                ->where('encuesta_plantilla_id', $plantilla->id)
                ->exists();

            if (!$existe) {
                $encuesta = EncuestaSatisfaccion::create([
                    'evento_id'             => $evento->id,
                    'user_id'               => $p->user_id,
                    'tipo'                  => $p->tipo,
                    'segmento'              => $segmento,
                    'token'                 => Str::random(40),
                    'encuesta_plantilla_id' => $plantilla->id,
                ]);

                $user = User::find($p->user_id);
                if ($user?->email) {
                    Mail::to($user->email)
                        ->send(new EncuestaSatisfaccionMail($encuesta->load(['evento','user','plantilla'])));
                    $enviados++;
                }
            }
        }

        return $enviados;
    }

PARTE 5 — EncuestaController: soporte de condicionales al responder
════════════════════════════════════════════════════════════════════════════════

En store(), ajusta para guardar respuesta con tipo correcto y manejar multiple:

    public function store(Request $request, string $token)
    {
        $encuesta = EncuestaSatisfaccion::with('plantilla')
            ->where('token', $token)->firstOrFail();

        if ($encuesta->completada()) {
            return back()->withErrors(['error' => 'Esta encuesta ya fue respondida.']);
        }

        $preguntas = $encuesta->plantilla?->preguntas ?? config('encuestas.preguntas');

        foreach ($preguntas as $pregunta) {
            $respuesta = $request->input($pregunta['id']);

            // Tipo multiple → array, serializar como JSON string
            if ($pregunta['tipo'] === 'multiple' && is_array($respuesta)) {
                $respuesta = implode(', ', array_filter($respuesta));
            }

            if ($respuesta !== null && $respuesta !== '' && $respuesta !== []) {
                EncuestaRespuesta::create([
                    'encuesta_satisfaccion_id' => $encuesta->id,
                    'pregunta'                 => $pregunta['texto'],
                    'tipo'                     => $pregunta['tipo'],
                    'respuesta'                => (string) $respuesta,
                ]);
            }
        }

        $encuesta->update(['completada_at' => now()]);

        return Inertia::render('Encuestas/Gracias', [
            'evento' => $encuesta->evento?->only(['nombre']),
        ]);
    }

    // useForm de @inertiajs/vue3

    const props = defineProps({ encuesta: Object, evento: Object, usuario: Object, preguntas: Array });

    const form = useForm(
        Object.fromEntries((props.preguntas ?? []).map(p => [p.id, p.tipo === 'multiple' ? [] : '']))
    );

    // ── Evaluador de condicionales ────────────────────────────────────────
    const preguntaVisible = (pregunta) => {
        if (!pregunta.condicion?.pregunta_id) return true;
        const { pregunta_id, operador, valor } = pregunta.condicion;
        const respuestaFuente = form[pregunta_id];
        if (respuestaFuente === undefined || respuestaFuente === '') return false;
        const rf = String(respuestaFuente);
        const vl = String(valor);
        switch (operador) {
            case 'igual':     return rf === vl;
            case 'diferente': return rf !== vl;
            case 'mayor':     return parseFloat(rf) > parseFloat(vl);
            case 'menor':     return parseFloat(rf) < parseFloat(vl);
            default:          return true;
        }
    };

    const submit = () => {
        form.post(route('encuestas.responder.store', props.encuesta.token));
    };
