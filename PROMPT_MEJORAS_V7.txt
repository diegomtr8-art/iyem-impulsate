PARTE C — Middleware EnsureAvisoAceptado (cubre TODOS los flujos de acceso)
---------------------------------------------------------------------------
Esta es la pieza central. Un middleware que intercepta a cualquier usuario autenticado que no
haya aceptado el aviso, sin importar cómo llegó (registro normal, Google, o usuario antiguo).

1. Crear `app/Http/Middleware/EnsureAvisoAceptado.php`:
   ```php
   public function handle(Request $request, Closure $next): Response
   {
       if (Auth::check() && is_null(Auth::user()->acepta_aviso_at)) {
           // Admins y super-admins están exentos — solo aplica a usuarios regulares
           if (!Auth::user()->hasRole('admin') && !Auth::user()->hasRole('super-admin')) {
               // Evitar loop: permitir las rutas del aviso y logout
               $rutasPermitidas = ['aviso.aceptar', 'aviso.aceptar.post', 'logout', 'aviso.privacidad'];
               if (!in_array($request->route()->getName(), $rutasPermitidas)) {
                   return redirect()->route('aviso.aceptar');
               }
           }
       }
       return $next($request);
   }
   ```

2. Registrar el alias del middleware en `bootstrap/app.php` (Laravel 11):
   ```php
   ->withMiddleware(function (Middleware $middleware) {
       $middleware->alias([
           // ... aliases existentes ...
           'aviso.aceptado' => \App\Http\Middleware\EnsureAvisoAceptado::class,
       ]);
   })
   ```

3. Aplicar el middleware en routes/web.php al grupo de rutas autenticadas (el grupo que ya
   usa `auth` y contiene dashboard, rol.seleccionar, perfil, paneles, etc.):
   ```php
   Route::middleware(['auth', 'aviso.aceptado'])->group(function () {
       // ... todas las rutas de usuarios autenticados (dashboard, perfil, citas, etc.)
   });
   ```
   Verificar que las rutas /aceptar-aviso queden FUERA de este grupo (son las que el
   middleware permite para no crear un loop de redirecciones).
