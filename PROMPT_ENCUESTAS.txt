DIAGNÓSTICO DEL SISTEMA ACTUAL (para que Claude Code no reinvente lo que ya existe)
--------------------------------------------------------------------------------------
Ya existe un sistema de encuestas de satisfacción, pero es más limitado de lo que se pide:

- `app/Models/EncuestaSatisfaccion.php` — tabla `encuestas_satisfaccion`: cada fila es el envío de
  una encuesta a UN participante de UN evento (`evento_id`, `user_id`, `tipo`, `token`,
  `completada_at`). Hoy `evento_id` y `user_id` son obligatorios (FK not-nullable).
- `app/Models/EncuestaRespuesta.php` — tabla `encuesta_respuestas`: cada fila es una pregunta+
  respuesta de una encuesta ya completada (`encuesta_satisfaccion_id`, `pregunta`, `respuesta`).
- Las PREGUNTAS de la encuesta NO están en base de datos: están fijas en `config/encuestas.php`
  (6 preguntas con tipos `escala` (1-5), `texto` (libre) y `binario` (Sí/No)). Esto es justo lo que

  por token): leen las preguntas de `config('encuestas.preguntas')` y renderizan
  `Encuestas/Responder.vue` (look exacto: preguntas tipo escala = 5 botones 1-5, binario = botones
  Sí/No, texto = textarea). Al completarse, renderiza `Encuestas/Gracias.vue`.
- `app/Http/Controllers/Admin/EventoController.php::enviarEncuestas(Evento $evento)` — ya existe:
  recorre los participantes APROBADOS de ese evento (tabla `evento_usuario`), crea una
  `EncuestaSatisfaccion` por participante que no la tenga ya, y envía `EncuestaSatisfaccionMail`.
  Esto vive en el panel de Eventos (ruta `admin.eventos.enviar-encuestas`), no en el de Encuestas.
- `app/Mail/EncuestaSatisfaccionMail.php` — Mailable que renderiza la vista Blade
  `resources/views/mail/encuesta-satisfaccion.blade.php` con el link `route('encuestas.responder',
  $token)`. El TEXTO de este correo (asunto/cuerpo) además ya es editable por separado en
  Admin > Super Admin > Plantillas de correo (`PlantillaCorreo` con `clave = 'encuesta_satisfaccion'`)
  — eso es la REDACCIÓN del correo, NO las preguntas de la encuesta. No confundir ambos sistemas;

- `app/Http/Controllers/Admin/EncuestaAdminController.php` + `resources/js/Pages/Admin/Encuestas/

public function guardarPlantilla(Request $request)
{
    $data = $request->validate([
        'id'                => 'nullable|exists:encuesta_plantillas,id',
        'nombre'            => 'required|string|max:150',
        'descripcion'       => 'nullable|string|max:500',
        'preguntas'         => 'required|array|min:1',
        'preguntas.*.id'    => 'required|string|max:80',
        'preguntas.*.tipo'  => 'required|in:escala,texto,binario',
        'preguntas.*.texto' => 'required|string|max:500',
    ]);

    EncuestaPlantilla::updateOrCreate(['id' => $data['id'] ?? null], [
        'nombre'      => $data['nombre'],
        'descripcion' => $data['descripcion'] ?? null,
        'preguntas'   => $data['preguntas'],
    ]);

    return back()->with('success', 'Plantilla guardada correctamente.');
}

public function activarPlantilla(EncuestaPlantilla $plantilla)
{
    EncuestaPlantilla::query()->update(['activa' => false]);
    $plantilla->update(['activa' => true]);
    return back()->with('success', "Plantilla \"{$plantilla->nombre}\" activada. Se usará en los próximos envíos.");
}

public function eliminarPlantilla(EncuestaPlantilla $plantilla)
{
    if ($plantilla->activa) {
        return back()->withErrors(['error' => 'No puedes eliminar la plantilla activa. Activa otra primero.']);
    }
    $plantilla->delete();
    return back()->with('success', 'Plantilla eliminada.');
}

```php
public function show(string $token)
{
    $encuesta = EncuestaSatisfaccion::with(['evento', 'user', 'plantilla'])
        ->where('token', $token)->firstOrFail();

    if ($encuesta->completada()) {
        return Inertia::render('Encuestas/Gracias', ['evento' => $encuesta->evento?->only(['nombre'])]);
    }

    $preguntas = $encuesta->plantilla?->preguntas ?? config('encuestas.preguntas');

    return Inertia::render('Encuestas/Responder', [
        'encuesta'  => $encuesta->only(['id', 'tipo', 'token']),
        'evento'    => $encuesta->evento?->only(['nombre', 'sector_economico']),
        'usuario'   => $encuesta->user?->only(['name']),
        'preguntas' => $preguntas,
    ]);
}

public function store(Request $request, string $token)
{
    $encuesta = EncuestaSatisfaccion::where('token', $token)->firstOrFail();
    if ($encuesta->completada()) {
        return back()->withErrors(['error' => 'Esta encuesta ya fue respondida.']);
    }

    $preguntas = $encuesta->plantilla?->preguntas ?? config('encuestas.preguntas');

    foreach ($preguntas as $pregunta) {
        $respuesta = $request->input($pregunta['id']);
        if ($respuesta !== null && $respuesta !== '') {
            EncuestaRespuesta::create([
                'encuesta_satisfaccion_id' => $encuesta->id,
                'pregunta'                 => $pregunta['texto'],
                'tipo'                     => $pregunta['tipo'],
                'respuesta'                => (string) $respuesta,
            ]);
        }
    }

    $encuesta->update(['completada_at' => now()]);
    return Inertia::render('Encuestas/Gracias', ['evento' => $encuesta->evento?->only(['nombre'])]);
}
```
Así, si todavía no se ha creado/activado ninguna plantilla, sigue funcionando igual que hoy
(usa `config('encuestas.preguntas')`); en cuanto haya una plantilla activa, se usa esa.

4A. Backend — ampliar EncuestaAdminController::index()

```php
public function index(Request $request)
{
    $eventoId = $request->get('evento_id');

    $base = EncuestaSatisfaccion::where('es_prueba', false);
    if ($eventoId) { $base->where('evento_id', $eventoId); }

    $totalEnviadas   = (clone $base)->count();
    $totalRespondidas = (clone $base)->whereNotNull('completada_at')->count();
    $tasaRespuesta    = $totalEnviadas > 0 ? round($totalRespondidas * 100 / $totalEnviadas, 1) : 0;

    // Promedio por pregunta tipo "escala" y % de "Sí" en preguntas tipo "binario"
    $respuestasQuery = EncuestaRespuesta::query()
        ->whereHas('encuesta', function ($q) use ($eventoId) {
            $q->where('es_prueba', false);
            if ($eventoId) { $q->where('evento_id', $eventoId); }
        });

    $metricasEscala = (clone $respuestasQuery)->where('tipo', 'escala')
        ->selectRaw('pregunta, AVG(CAST(respuesta AS DECIMAL(3,1))) as promedio, COUNT(*) as total')
        ->groupBy('pregunta')->get();

    $metricasBinario = (clone $respuestasQuery)->where('tipo', 'binario')
        ->selectRaw("pregunta, SUM(CASE WHEN respuesta = 'Sí' THEN 1 ELSE 0 END) as positivas, COUNT(*) as total")
        ->groupBy('pregunta')->get()
        ->map(fn ($r) => ['pregunta' => $r->pregunta, 'porcentaje_si' => $r->total > 0 ? round($r->positivas * 100 / $r->total, 1) : 0]);

    $ultimasRespondidas = EncuestaSatisfaccion::with(['evento', 'user', 'respuestas'])
        ->where('es_prueba', false)
        ->whereNotNull('completada_at')
        ->when($eventoId, fn ($q) => $q->where('evento_id', $eventoId))
        ->orderByDesc('completada_at')
        ->take(10)
        ->get()
        ->map(fn ($e) => [
            'id'            => $e->id,
            'evento'        => $e->evento?->nombre,
            'usuario'       => $e->user?->name,
            'tipo'          => $e->tipo,
            'completada_at' => $e->completada_at->format('d/m/Y H:i'),
            'respuestas'    => $e->respuestas->map(fn ($r) => ['pregunta' => $r->pregunta, 'respuesta' => $r->respuesta])->values(),
        ]);

    $encuestas = $base->with(['evento', 'user'])->orderByDesc('created_at')->paginate(50)->through(/* igual que hoy */);
    $eventos = Evento::orderByDesc('created_at')->get(['id', 'nombre']);

    return Inertia::render('Admin/Encuestas/Index', [
        'encuestas'          => $encuestas,
        'eventos'            => $eventos,
        'filtroEvento'       => $eventoId,
        'metricas'           => [
            'total_enviadas'    => $totalEnviadas,
            'total_respondidas' => $totalRespondidas,
            'tasa_respuesta'    => $tasaRespuesta,
            'escala'            => $metricasEscala,
            'binario'           => $metricasBinario,
        ],
        'ultimasRespondidas' => $ultimasRespondidas,
    ]);
}
```
