PROBLEMA
========
En EventosSidebar.vue la tarjeta del evento activo muestra "✓ Registrado"
incluso para usuarios de bazar que solo tienen una solicitud pendiente de revisión.

La raíz: el computed `estaRegistrado` solo mira `registradoEnEvento.comprador`
o `.proveedor` con estado='aprobado'. Para bazares, el usuario se registra como
'expositor', tipo que el middleware no incluye en `registradoEnEvento`.
Resultado: el sidebar muestra "Regístrate" (si expositor no detectado) o
"Registrado" (si el usuario también tiene un registro comprador de un evento
anterior) — ambos son incorrectos cuando la solicitud está pendiente.

La solución: añadir `expositor` al prop `registradoEnEvento` en el middleware,
y en el sidebar mostrar el estado real del bazar en lugar de texto genérico.


CAMBIO 1 — app/Http/Middleware/HandleInertiaRequests.php
=========================================================

En el closure de `registradoEnEvento`, agregar la clave 'expositor' al array
que se retorna (junto a 'comprador' y 'proveedor').

Encuentra el bloque:

        'registradoEnEvento' => function () use ($request) {
            $evento = Evento::activo();
            if (!$evento || !$request->user()) {
                return ['comprador' => null, 'proveedor' => null];
            }
            $registros = DB::table('evento_usuario')
                ->where('evento_id', $evento->id)
                ->where('user_id', $request->user()->id)
                ->get()
                ->keyBy('tipo');

            return [
                'comprador' => $registros->has('comprador') ? [
                    'estado'         => $registros['comprador']->estado,
                    'motivo_rechazo' => $registros['comprador']->motivo_rechazo,
                ] : null,
                'proveedor' => $registros->has('proveedor') ? [
                    'estado'         => $registros['proveedor']->estado,
                    'motivo_rechazo' => $registros['proveedor']->motivo_rechazo,
                ] : null,
            ];
        },

Reemplázalo por:

        'registradoEnEvento' => function () use ($request) {
            $evento = Evento::activo();
            if (!$evento || !$request->user()) {
                return ['comprador' => null, 'proveedor' => null, 'expositor' => null];
            }
            $registros = DB::table('evento_usuario')
                ->where('evento_id', $evento->id)
                ->where('user_id', $request->user()->id)
                ->get()
                ->keyBy('tipo');

            return [
                'comprador' => $registros->has('comprador') ? [
                    'estado'         => $registros['comprador']->estado,
                    'motivo_rechazo' => $registros['comprador']->motivo_rechazo,
                ] : null,
                'proveedor' => $registros->has('proveedor') ? [
                    'estado'         => $registros['proveedor']->estado,
                    'motivo_rechazo' => $registros['proveedor']->motivo_rechazo,
                ] : null,
                'expositor' => $registros->has('expositor') ? [
                    'estado'           => $registros['expositor']->estado,
                    'seleccionado'     => (bool) $registros['expositor']->seleccionado,
                    'motivo_rechazo'   => $registros['expositor']->motivo_rechazo,
                ] : null,
            ];
        },


CAMBIO 2 — resources/js/Components/EventosSidebar.vue
======================================================

--- Parte 1: Agregar computed para el expositor ---

En el bloque <script setup>, justo después de la línea:

const estaRegistrado = computed(() => {
    const tipo = activeRole.value === 'proveedor' ? 'proveedor' : 'comprador';
    return registradoEnEvento.value?.[tipo]?.estado === 'aprobado';
});

Agrega:

const expositorRegistro = computed(() => registradoEnEvento.value?.expositor ?? null);

ESTADOS QUE MUESTRA AHORA (para bazar)
========================================
- Sin solicitud            → botón "Regístrate" (guinda)
- expositor.estado=pendiente → "🕐 Solicitud en Revisión" (ámbar)
- expositor.estado=aprobado, seleccionado=false → "✓ En Evaluación" (azul)
- expositor.estado=aprobado, seleccionado=true  → "✓ Seleccionado" (verde)
