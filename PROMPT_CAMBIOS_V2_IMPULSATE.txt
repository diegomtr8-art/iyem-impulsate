CAMBIO 1 — AUTO-REGISTRO AL EVENTO: PROVEEDOR (perfil 100% completo)
════════════════════════════════════════════════════════════════════════════════

Cuando un proveedor complete su perfil al 100%, el sistema debe registrarlo
automáticamente al evento activo de Restaurantes como proveedor aprobado.

CAMPOS OBLIGATORIOS para considerarlo completo (ajusta si alguno ya existe):

  Del modelo Restaurantero:
    - nombre           (nombre del negocio)
    - descripcion
    - telefono
    - municipio
    - rfc
    - sitio_web
    - categoria_id     (o 'categoria' según cómo esté en tu BD — verifica)
    - foto             (imagen del negocio)
    - credito_tipo     ('si'|'a_negociar'|'no')
    - pago_contraentrega
    - acepta_factura
    - entrega_domicilio
    - cobertura
    - forma_entrega

  Relación productos:
    - Al menos 1 producto con foto (whereNotNull('foto'))

  CAMPOS NO OBLIGATORIOS (NO se validan para perfil_completo):
    - tiempo_vida_anaquel, aplica_tiempo_vida
    - req_tabla_nutrimental, req_etiquetado_nom, req_codigo_barras
    - req_registro_marca, req_cert_calidad
    - apoyo_tabla_nutrimental, apoyo_etiquetado_nom, apoyo_registro_marca
    - requiere_refrigeracion, requiere_congelacion

Archivo: app/Models/Restaurantero.php

Reemplaza (o crea) calcularPerfilCompleto() con esta versión exacta:

    public function calcularPerfilCompleto(): bool
    {
        $camposRequeridos = [
            'nombre',
            'descripcion',
            'telefono',
            'municipio',
            'rfc',
            'sitio_web',
            'credito_tipo',
            'pago_contraentrega',
            'acepta_factura',
            'entrega_domicilio',
            'cobertura',
            'forma_entrega',
        ];

        foreach ($camposRequeridos as $campo) {
            $valor = $this->$campo;
            // null y string vacío = incompleto; false (bool) = válido
            if (is_null($valor) || $valor === '') {
                return false;
            }
        }

        // categoria_id O categoria (usa el que exista en tu tabla)
        $tieneCategoria = !empty($this->categoria_id) || !empty($this->categoria);
        if (!$tieneCategoria) return false;

        // Imagen del negocio
        if (empty($this->foto)) return false;

        // Al menos 1 producto con foto
        $tieneProductoConFoto = $this->productos()
            ->whereNotNull('foto')
            ->where('foto', '!=', '')
            ->exists();
        if (!$tieneProductoConFoto) return false;

        return true;
    }

En el mismo modelo, asegúrate de que el boot() ejecute la lógica de
auto-registro cuando el perfil se complete:

    protected static function boot()
    {
        parent::boot();

        static::saved(function (Restaurantero $restaurantero) {
            $completo = $restaurantero->calcularPerfilCompleto();

            // Actualiza la columna perfil_completo (evita loop con updateQuietly)
            if ((bool)$restaurantero->perfil_completo !== $completo) {
                $restaurantero->updateQuietly(['perfil_completo' => $completo]);
                if ($restaurantero->user_id) {
                    \DB::table('users')
                        ->where('id', $restaurantero->user_id)
                        ->update(['perfil_completo' => $completo]);
                }
            }

            // Auto-registro al evento solo cuando acaba de completarse
            if ($completo && !$restaurantero->getOriginal('perfil_completo')) {
                static::autoRegistrarAlEvento($restaurantero);
            }
        });
    }

    protected static function autoRegistrarAlEvento(Restaurantero $restaurantero): void
    {
        $evento = \App\Models\Evento::where('activo', true)->latest()->first();
        if (!$evento) return;

        $yaRegistrado = \DB::table('evento_usuario')
            ->where('evento_id', $evento->id)
            ->where('user_id',   $restaurantero->user_id)
            ->where('tipo',      'proveedor')
            ->exists();

        if ($yaRegistrado) return;

        \DB::table('evento_usuario')->insert([
            'evento_id'     => $evento->id,
            'user_id'       => $restaurantero->user_id,
            'tipo'          => 'proveedor',
            'estado'        => 'aprobado',
            'respondido_at' => now(),
            'created_at'    => now(),
            'updated_at'    => now(),
        ]);

        // Vincular edicion al evento (si el modelo Restaurantero tiene edicion_id)
        \DB::table('restauranteros')
            ->where('id', $restaurantero->id)
            ->update(['edicion_id' => $evento->id]);

        // Notificación interna
        if (class_exists(\App\Models\Notificacion::class)) {
            \App\Models\Notificacion::crear(
                $restaurantero->user_id,
                'perfil_aprobado',
                '¡Tu perfil está completo!',
                'Tu perfil de proveedor fue aprobado automáticamente. Ya apareces en el directorio del evento "' . $evento->nombre . '".'
            );
        }
    }

VERIFICACIÓN DE LOS 6 CAMBIOS
════════════════════════════════════════════════════════════════════════════════

CAMBIO 1 — Auto-registro proveedor:
  1. Crea un proveedor nuevo (sin perfil completo)
  2. Entra al panel y llena TODOS los campos requeridos incluyendo foto y producto
  3. Guarda
  4. Verifica en evento_usuario: debe existir fila tipo='proveedor' estado='aprobado'
  5. Verifica restaurantero.perfil_completo = 1 en BD
  6. Verifica que aparece en el directorio público

CAMBIO 2 — Auto-registro comprador:
  a) Con es_restaurantero = true:
     - Registra comprador nuevo, llena perfil, marca "¿Eres restaurantero?"
     - Verifica evento_usuario: tipo='comprador' estado='aprobado'
  b) Con es_restaurantero = false:
     - Registra comprador nuevo, llena perfil, NO marca "¿Eres restaurantero?"
     - Verifica que NO existe fila en evento_usuario

CAMBIO 3 — Lista compradores en agenda:
  1. Ve a /admin/agenda/crear
  2. Selecciona un proveedor
  3. Verifica que la lista de compradores muestra TODOS los usuarios con rol cliente
  4. Busca por nombre o municipio — filtra correctamente
  5. Selecciona un comprador de la lista, asígnalo a un slot
  6. Verifica que el comprador queda marcado con ✓

CAMBIO 4 — ¿Eres restaurantero? en Mi Panel:
  1. Entra a /mi-panel con un usuario que tiene es_restaurantero=false
  2. Localiza la sección "Editar mis datos"
  3. Activa el checkbox "¿Eres restaurantero?"
  4. Guarda los cambios
  5. Verifica que aparece en evento_usuario como comprador aprobado

CAMBIO 5 — "Ver Proveedores":
  1. Ve a la sección donde aparece el evento "Alimentos y Bebidas"
  2. Verifica que el link dice "Ver Proveedores" (no "Más información")
  3. Verifica que el href apunta a https://impulsate.iyemyucatan.com/proveedores

CAMBIO 6 — Modal al entrar al panel del proveedor:
  1. Abre una sesión nueva con un proveedor que tiene perfil incompleto
  2. Ve a /proveedor/panel
  3. Verifica que aparece el modal con los campos faltantes
  4. Verifica la barra de progreso porcentual
  5. Cierra el modal con "Más tarde" → debe cerrarse
  6. Navega a otra sección y regresa a /proveedor/panel
  7. Verifica que el modal NO vuelve a aparecer en la misma sesión
  8. Abre una ventana de incógnito → el modal debe aparecer nuevamente

DEPLOY A PRODUCCIÓN

Ejecuta en este orden en el servidor:

    # 1. Actualiza el código
    cd /var/www/html/citas

    # 2. Dependencias PHP (si hay nuevas)
    composer install --no-dev --optimize-autoloader

    php artisan migrate --force

    # 4. Compila los assets Vue/JS (REQUERIDO — hay cambios en .vue)
    npm ci
    npm run build

    # 5. Limpia caché de Laravel
    php artisan optimize
    php artisan config:cache
    php artisan route:cache
    php artisan view:cache

    # 6. Reinicia colas si usas jobs para correos
    php artisan queue:restart

No hay seeders nuevos en este prompt.
No hay rollback necesario para los cambios de Vue (son archivos estáticos).

Si algo falla tras el deploy:
    php artisan migrate:rollback --step=1   (solo si hubo error en migraciones)
    php artisan cache:clear
    php artisan optimize:clear
