ANIMACIÓN DE CAMINAR (ciclo continuo via requestAnimationFrame):
  Cada figura tiene propiedades: speed, direction (±1 = izquierda o derecha), phase.

  En cada frame:
  ```js
  const t = clock.getElapsedTime()
  peatones.forEach(p => {
    // Mover horizontalmente
    p.group.position.x += p.speed * p.direction * delta

    // Rebote en bordes: si sale del rango X, invertir dirección y voltear
    if (p.group.position.x > 28 || p.group.position.x < -28) {
      p.direction *= -1
      p.group.rotation.y = p.direction > 0 ? 0 : Math.PI
    }

    // Ciclo de caminar: oscilar piernas y brazos
    const cycle = Math.sin(t * 4.5 + p.phase)
    p.piernaIzq.rotation.x = cycle * 0.45
    p.piernaDer.rotation.x = -cycle * 0.45
    p.brazoIzq.rotation.x = -cycle * 0.3
    p.brazoDer.rotation.x = cycle * 0.3

    // Ligero bounce vertical del torso
    p.group.position.y = p.baseY + Math.abs(Math.sin(t * 4.5 + p.phase)) * 0.025
  })
  ```

  Speed por figura: random entre 0.015 y 0.04 (unidades por frame a 60fps).
  Fase por figura: random 0..2π para que no se muevan sincronizadas.
  Distribución Z: cada figura en un Z aleatorio entre -4.8 y -3.2 (dentro del Paso de Gente).

SOMBRAS DE PERSONAS: cada parte de la figura tiene castShadow = true.

SECCIÓN K — LOOP DE ANIMACIÓN PRINCIPAL
============================================================
```js
const clock = new THREE.Clock()
let animFrameId

const animate = () => {
  animFrameId = requestAnimationFrame(animate)
  const delta = clock.getDelta()
  const elapsed = clock.getElapsedTime()

  // 1. Actualizar controles de cámara (damping)
  updateCameraControls(delta)

  // 2. Animar peatones
  animatePeatones(elapsed, delta)

  // 3. Animar figuras en gradas (bounce sutil)
  animateGradaFigures(elapsed)

  // 4. Hover de stand (raycasting)
  if (needsRaycast) updateHover()

  // 5. Pulsación del stand seleccionado (escala Y del techo ±0.005)
  if (selectedMesh) {
    const techo = selectedMesh.userData.techoMesh
    if (techo) techo.scale.y = 1 + Math.sin(elapsed * 2) * 0.02
  }

  // 6. Flechas de Paso de Gente (opacidad pulsante)
  animarFlechas(elapsed)

  renderer.render(scene, camera)
}

animate()

// Cleanup en onUnmounted:
cancelAnimationFrame(animFrameId)
renderer.dispose()
```

SECCIÓN L — OPTIMIZACIONES DE RENDIMIENTO MÓVIL
============================================================
- En dispositivos de bajo rendimiento (detectar con < 4 CPU cores o GPU tier):
  * Reducir número de peatones a 8 (en vez de 20)
  * Desactivar sombras: renderer.shadowMap.enabled = false
  * Reducir calidad shadow map a 512
  * Usar renderer.setPixelRatio(1) en lugar de devicePixelRatio

- Detectar rendimiento con:
  ```js
  const isLowEnd = navigator.hardwareConcurrency <= 2
  if (isLowEnd) { /* ajustes de bajo rendimiento */ }
  ```

- Geometrías compartidas: crear una sola geometría por tipo y reutilizar con clone() o
  InstancedMesh para las gradas/figuras repetitivas.

- Raycasting: solo ejecutar en mousemove/touchmove, no en cada frame.
  Usar throttle de 50ms para el evento de mouse.
