PASO 3 — SI EL SERVIDOR NO TIENE NODE: SUBIR EL BUILD LOCALMENTE
════════════════════════════════════════════════════════════════════════════════

Si node --version falla en el servidor, el build debe hacerse LOCALMENTE y
subirse completo al servidor.

    npm run build

Esto genera la carpeta: C:\xampp\htdocs\citas\public\build\

Luego sube TODA esa carpeta al servidor con rsync o scp:

    scp -P 65002 -r C:\xampp\htdocs\citas\public\build \
        u489236361@195.35.38.222:/home/u489236361/domains/impulsate.iyemyucatan.com/public_html/public/

    # O con rsync (más seguro, solo sube cambios):
    rsync -avz --delete -e "ssh -p 65002" \

        u489236361@195.35.38.222:/home/u489236361/domains/impulsate.iyemyucatan.com/public_html/public/build/
