─ 1B. Nuevo método en EncuestaAdminController ───────────────────────────────

    public function enviarRecordatorioPrueba(Request $request)
    {
        $request->validate([
            'email'        => 'required|email',
            'plantilla_id' => 'nullable|exists:encuesta_plantillas,id',
        ]);

        $plantilla = $request->plantilla_id
            ? EncuestaPlantilla::find($request->plantilla_id)
            : EncuestaPlantilla::where('activa', true)->first();

        // Crear encuesta fantasma de prueba (es_prueba = true)
        $encuesta = EncuestaSatisfaccion::create([
            'evento_id'             => null,
            'user_id'               => null,
            'tipo'                  => 'proveedor',
            'token'                 => \Illuminate\Support\Str::random(40),
            'encuesta_plantilla_id' => $plantilla?->id,
            'es_prueba'             => true,
            'email_prueba'          => $request->email,
        ]);

        \Illuminate\Support\Facades\Mail::to($request->email)
            ->send(new \App\Mail\EncuestaRecordatorioMail($encuesta->load('plantilla')));

        return back()->with('success', "Correo de recordatorio de prueba enviado a {$request->email}.");
    }

CAMBIO 2 — ELIMINAR TODAS LAS RESPUESTAS DE UNA PERSONA
════════════════════════════════════════════════════════════════════════════════

OBJETIVO: En la lista de encuestas completadas (Admin/Encuestas/Index.vue) y en
la vista de detalle (VerRespuesta.vue), poder borrar completamente los registros

Esto permite que pueda volver a recibir la encuesta si es necesario.

─ 2A. Nueva ruta ────────────────────────────────────────────────────────────

        [\App\Http\Controllers\Admin\EncuestaAdminController::class, 'eliminarRespuestas'])

─ 2B. Nuevo método en EncuestaAdminController ───────────────────────────────

    public function eliminarRespuestas(EncuestaSatisfaccion $encuesta)
    {
        $nombre = $encuesta->user?->name ?? $encuesta->email_prueba ?? "ID {$encuesta->id}";

        // Borrar respuestas individuales primero (FK)
        $encuesta->respuestas()->delete();

        // Borrar el registro de encuesta (permite reenvío futuro)
        $encuesta->delete();

        return back()->with('success', "Respuestas de {$nombre} eliminadas. Puede volver a recibir la encuesta.");
    }

CAMBIO 3 — POPUP CON CONTEO DE RECORDATORIOS ENVIADOS EXITOSAMENTE

OBJETIVO: Cuando el admin hace clic en "⏰ Recordatorio a pendientes", en lugar

─ 3A. Modificar enviarRecordatorio en EncuestaAdminController ───────────────

REEMPLAZAR el método enviarRecordatorio existente por esta versión que
devuelve datos detallados mediante sesión flash:

    public function enviarRecordatorio(Request $request)
    {
        $request->validate([
            'evento_id' => 'required|exists:eventos,id',
        ]);

        $pendientes = EncuestaSatisfaccion::with('user')
            ->where('evento_id', $request->evento_id)
            ->where('es_prueba', false)
            ->whereNull('completada_at')
            ->get();

        $yaContestaron = EncuestaSatisfaccion::where('evento_id', $request->evento_id)
            ->where('es_prueba', false)
            ->whereNotNull('completada_at')
            ->count();

        if ($pendientes->isEmpty()) {
            return back()->with('recordatorio_resultado', [
                'enviados'       => 0,
                'ya_contestaron' => $yaContestaron,
                'personas'       => [],
                'mensaje'        => '¡Todos han contestado!',
            ]);
        }

        $enviados = 0;
        $personas = [];

        foreach ($pendientes as $encuesta) {
            \App\Jobs\SendRecordatorioJob::dispatch($encuesta->id)
                ->onQueue('encuestas');
            $enviados++;
            $personas[] = [
                'nombre' => $encuesta->user?->name ?? $encuesta->email_prueba ?? '—',
                'email'  => $encuesta->user?->email ?? $encuesta->email_prueba ?? '—',
                'tipo'   => $encuesta->tipo,
            ];
        }

        return back()->with('recordatorio_resultado', [
            'enviados'       => $enviados,
            'ya_contestaron' => $yaContestaron,
            'personas'       => $personas,
            'mensaje'        => "Recordatorio enviado a {$enviados} persona(s) pendiente(s).",
        ]);
    }
