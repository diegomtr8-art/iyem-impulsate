Modifica calcularPerfilCompleto() para validar TODOS los campos requeridos:

    public function calcularPerfilCompleto(): bool
    {
        // Campos del modelo restaurantero
        $camposRestaurantero = [
            'nombre',           // nombre del negocio
            'descripcion',
            'telefono',
            'municipio',
            'rfc',
            'sitio_web',
            'categoria_id',     // o 'categoria' si es string; usa el que exista
            'foto',             // imagen del negocio
            'credito_tipo',     // 'si' | 'a_negociar' | 'no'
            'pago_contraentrega',
            'acepta_factura',
            'regimen_fiscal',
            'entrega_domicilio',
            'cobertura',
            'forma_entrega',
        ];

        foreach ($camposRestaurantero as $campo) {
            if (empty($this->$campo) && $this->$campo !== false && $this->$campo !== 0) {
                return false;
            }
        }

        // Debe tener al menos 1 producto con foto
        $tieneProductoConFoto = $this->productos()
            ->whereNotNull('foto')
            ->where('foto', '!=', '')
            ->exists();

        if (!$tieneProductoConFoto) {
            return false;
        }

        return true;
    }

Agrega el boot() para auto-aprobar al evento cuando el perfil se complete:

    protected static function boot()
    {
        parent::boot();

        static::saved(function (Restaurantero $restaurantero) {
            $completo = $restaurantero->calcularPerfilCompleto();

            if ($completo !== (bool) $restaurantero->getOriginal('perfil_completo')
                || ($completo && !$restaurantero->user->perfil_completo)) {

                $restaurantero->update(['perfil_completo' => $completo]);
                $restaurantero->user->update(['perfil_completo' => $completo]);

                if ($completo) {
                    static::autoRegistrarAlEvento($restaurantero);
                }
            }
        });
    }

    protected static function autoRegistrarAlEvento(Restaurantero $restaurantero): void
    {
        $evento = \App\Models\Evento::where('activo', true)->latest()->first();
        if (!$evento) return;

        $yaRegistrado = \DB::table('evento_usuario')
            ->where('evento_id', $evento->id)
            ->where('user_id', $restaurantero->user_id)
            ->where('tipo', 'proveedor')
            ->exists();

        if (!$yaRegistrado) {
            \DB::table('evento_usuario')->insert([
                'evento_id'      => $evento->id,
                'user_id'        => $restaurantero->user_id,
                'tipo'           => 'proveedor',
                'estado'         => 'aprobado',
                'respondido_at'  => now(),
                'created_at'     => now(),
                'updated_at'     => now(),
            ]);

            // Vincular el restaurantero al evento
            $restaurantero->update(['edicion_id' => $evento->id]);

            // Notificación al usuario
            \App\Models\Notificacion::crear(
                $restaurantero->user_id,
                'perfil_aprobado',
                '¡Perfil completo y aprobado!',
                'Tu perfil de proveedor está completo. Ya apareces en el directorio del evento "' . $evento->nombre . '".'
            );
        }
    }

                : '2026-07-21';

            $slots = [];
            $inicio = \Carbon\Carbon::parse($fechaEvento . ' 09:00:00');
            $fin    = \Carbon\Carbon::parse($fechaEvento . ' 17:00:00');
            while ($inicio->lt($fin)) {
                $slots[] = [
                    'inicio' => $inicio->toIso8601String(),
                    'fin'    => $inicio->copy()->addMinutes(30)->toIso8601String(),
                    'label'  => $inicio->format('H:i'),
                ];
                $inicio->addMinutes(30);
            }

            return Inertia::render('Admin/Agenda/Crear', [
                'evento'      => $evento,
                'proveedores' => $proveedores,
                'compradores' => $compradores,
                'slots'       => $slots,
            ]);
        }

        // Guardar propuesta (borrador o envío inmediato)
        public function store(Request $request)
        {
            $request->validate([
                'restaurantero_id' => 'required|exists:restauranteros,id',
                'citas'            => 'required|array|min:1',
                'citas.*.user_id'  => 'required|exists:users,id',
                'citas.*.slot_inicio' => 'required|date',
                'citas.*.slot_fin'    => 'required|date|after:citas.*.slot_inicio',
                'enviar'           => 'boolean',
            ]);

            $evento = Evento::where('activo', true)->latest()->firstOrFail();

            // Verificar que no haya propuesta activa para este proveedor
            $existente = AgendaPropuesta::where('evento_id', $evento->id)
                ->where('restaurantero_id', $request->restaurantero_id)
                ->whereIn('estado', ['pendiente'])
                ->first();

            if ($existente) {
                return back()->withErrors([
                    'error' => 'Ya existe una propuesta pendiente para este proveedor.'
                ]);
            }

            // Verificar conflictos de horario para cada comprador
            foreach ($request->citas as $cita) {
                $conflicto = AgendaPropuestaCita::where('user_id', $cita['user_id'])
                    ->whereHas('agenda', function ($q) use ($evento) {
                        $q->where('evento_id', $evento->id)
                          ->where('estado', 'aceptada');
                    })
                    ->where(function ($q) use ($cita) {
                        $q->whereBetween('slot_inicio', [$cita['slot_inicio'], $cita['slot_fin']])
                          ->orWhereBetween('slot_fin', [$cita['slot_inicio'], $cita['slot_fin']]);
                    })
                    ->exists();

                if ($conflicto) {
                    $comprador = User::find($cita['user_id']);
                    return back()->withErrors([
                        'error' => 'El comprador ' . ($comprador->nombre_empresa ?? $comprador->name) .
                                   ' ya tiene una cita confirmada en ese horario.'
                    ]);
                }
            }

            DB::transaction(function () use ($request, $evento) {
                $propuesta = AgendaPropuesta::create([
                    'evento_id'        => $evento->id,
                    'restaurantero_id' => $request->restaurantero_id,
                    'admin_id'         => auth()->id(),
                    'estado'           => 'pendiente',
                ]);

                foreach ($request->citas as $cita) {
                    AgendaPropuestaCita::create([
                        'agenda_propuesta_id' => $propuesta->id,
                        'user_id'             => $cita['user_id'],
                        'slot_inicio'         => $cita['slot_inicio'],
                        'slot_fin'            => $cita['slot_fin'],
                    ]);
                }

                if ($request->boolean('enviar')) {
                    $this->enviarCorreo($propuesta);
                }
            });

            return redirect()->route('admin.agenda.index')
                ->with('success', 'Propuesta de agenda guardada' .
                    ($request->boolean('enviar') ? ' y enviada al proveedor.' : '.'));
        }

        // Enviar correo manualmente desde la lista
        public function enviar(AgendaPropuesta $agenda)
        {
            if ($agenda->estado !== 'pendiente') {
                return back()->withErrors(['error' => 'Solo se pueden enviar propuestas pendientes.']);
            }

            $this->enviarCorreo($agenda);

            return back()->with('success', 'Correo enviado al proveedor.');
        }

        // Eliminar propuesta (solo si es pendiente y no enviada)
        public function destroy(AgendaPropuesta $agenda)
        {
            if ($agenda->estado === 'aceptada') {
                return back()->withErrors(['error' => 'No puedes eliminar una propuesta ya aceptada.']);
            }
            $agenda->delete();
            return back()->with('success', 'Propuesta eliminada.');
        }

        // Método privado para enviar el correo
        private function enviarCorreo(AgendaPropuesta $propuesta): void
        {
            $propuesta->load([
                'restaurantero.user',
                'citas.comprador:id,name,nombre_empresa',
                'evento',
            ]);

            $token = $propuesta->generarToken();

            $urlAceptar = route('agenda.aceptar', $token);
            $urlRechazar = route('agenda.rechazar', $token);

            // Construir lista de citas para el correo
            $listaCitas = $propuesta->citas->map(function ($c) {
                $nombre = $c->comprador->nombre_empresa ?? $c->comprador->name;
                $hora = \Carbon\Carbon::parse($c->slot_inicio)->format('H:i') . ' – ' .
                        \Carbon\Carbon::parse($c->slot_fin)->format('H:i');
                return $hora . ' → ' . $nombre;
            })->join("\n");

            $plantilla = \App\Models\PlantillaCorreo::where('clave', 'agenda_propuesta')
                ->where('activo', true)
                ->first();

            if ($plantilla) {
                $mail = new \App\Mail\PlantillaCorreoMail($plantilla, [
                    '{{nombre_proveedor}}' => $propuesta->restaurantero->nombre,
                    '{{nombre_evento}}'    => $propuesta->evento->nombre,
                    '{{fecha_evento}}'     => \Carbon\Carbon::parse(
                        $propuesta->evento->fecha_inicio
                    )->format('d \d\e F \d\e Y'),
                    '{{lista_citas}}'      => $listaCitas,
                    '{{url_aceptar}}'      => $urlAceptar,
                    '{{url_rechazar}}'     => $urlRechazar,
                ]);
                Mail::to($propuesta->restaurantero->user->email)->send($mail);
            }

            $propuesta->update(['enviada_at' => now()]);
        }
    }

        {

                ->where('estado', 'pendiente')

                    ]);

                // Notificar al proveedor

Métodos:
    function asignarComprador(slot) {
        if (!compradorActivo.value || yaAsignado(compradorActivo.value.id)) return;
        citasAsignadas.value.push({
            slot_inicio: slot.inicio,
            slot_fin:    slot.fin,
            user_id:     compradorActivo.value.id,
            nombreComprador: compradorActivo.value.nombre_empresa ?? compradorActivo.value.name,
        });
        compradorActivo.value = null;
    }
    function quitarAsignacion(slotInicio) {
        citasAsignadas.value = citasAsignadas.value.filter(c => c.slot_inicio !== slotInicio);
    }
    function getAsignacion(slotInicio) {
        return citasAsignadas.value.find(c => c.slot_inicio === slotInicio);
    }

   verifica en el modelo y la migración actual de restauranteros y users.

2. CATEGORIAS: El campo de categoría en restauranteros puede ser 'categoria' (string)
   o 'categoria_id' (FK a tabla categorias). Usa el que ya exista.
   Para cargar las categorías en Panel.vue y CompletarPerfil.vue, pásalas como
   prop desde el controller: Categoria::orderBy('nombre')->get(['id','nombre'])

3. MODELO CITA: El modelo Cita puede tener campos distintos a los que usé
   (restaurantero_id, cliente_id, inicio, fin, estado). Lee el modelo antes
   de crear las citas en AgendaPublicaController::aceptar().

4. AUTENTICACIÓN EN RUTAS PÚBLICAS: Las rutas /agenda/propuesta/{token} etc.
   NO requieren auth. El token actúa como llave. Quita el middleware auth si
   está heredado del grupo de rutas padre.

5. EL CORREO DE AGENDA: Si PlantillaCorreoMail no puede renderizar links HTML
   (botones), puedes crear un Mailable dedicado AgendaPropuestaMail con su
   propio blade template en resources/views/mails/agenda-propuesta.blade.php.

6. USUARIOS EXISTENTES: Los usuarios registrados ANTES de estos cambios tienen
   perfil_completo=true (ya puesto en la migración anterior). NO se les pedirá
   volver a completar el perfil. Los nuevos sí pasarán por el wizard.

7. COLOR GUINDA: Todo elemento nuevo debe usar guinda-800 / guinda-700 / guinda-50.
   NUNCA azul, índigo o morado. El color guinda ya está en tailwind.config.js.
