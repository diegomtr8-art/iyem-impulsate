CAMBIO 2 — AgendaController: métodos show() y destroy()
════════════════════════════════════════════════════════════════════════════════

Busca el AgendaController en app/Http/Controllers/ (puede llamarse
AgendaController.php o AdminAgendaController.php). Agrega estos dos métodos:

    public function show(\App\Models\AgendaPropuesta $propuesta)
    {
        $propuesta->load([
            'comprador:id,name,nombre_empresa,email',
            'evento:id,nombre,fecha_inicio',
            'citas.restaurantero:id,nombre,foto',
        ]);

        // También cargar las citas reales creadas si la propuesta fue aceptada
        $citasConfirmadas = [];
        if ($propuesta->estado === 'aceptada') {
            $citasConfirmadas = \App\Models\Cita::where('cliente_id', $propuesta->user_id)
                ->where('evento_id', $propuesta->evento_id)
                ->with('restaurantero:id,nombre,foto')
                ->orderBy('inicio')
                ->get();
        }

        return \Inertia\Inertia::render('Admin/Agenda/Show', [
            'propuesta'        => $propuesta,
            'citasConfirmadas' => $citasConfirmadas,
        ]);
    }

    public function destroy(\App\Models\AgendaPropuesta $propuesta)
    {
        // 1. Borrar citas reales confirmadas si la propuesta fue aceptada
        if ($propuesta->estado === 'aceptada') {
            \App\Models\Cita::where('cliente_id', $propuesta->user_id)
                ->where('evento_id', $propuesta->evento_id)
                ->delete();
        }

        // 2. Borrar citas propuestas (tabla agenda_propuesta_citas)
        $propuesta->citas()->delete();

        // 3. Borrar la propuesta
        $propuesta->delete();

        return redirect()->route('admin.agenda.index')
            ->with('success', 'Propuesta de agenda eliminada correctamente.');
    }

NOTA IMPORTANTE: Verifica el nombre exacto de la relación en AgendaPropuesta.
  - Si el método de relación se llama citas() → usa $propuesta->citas()->delete()
  - Si se llama slots() o propuestaCitas() → ajusta en consecuencia
  
  Verifica también el campo cliente_id en el modelo Cita. Si se llama
  user_id en lugar de cliente_id, ajusta el query de borrado.

En el <script setup> del mismo archivo, agrega:

    import { ref } from 'vue';
    import { Link, router } from '@inertiajs/vue3';

    const modalBorrado      = ref(false);
    const propuestaABorrar  = ref(null);
    const borrando          = ref(false);

    const confirmarBorrado = (propuesta) => {
        propuestaABorrar.value = propuesta;
        modalBorrado.value = true;
    };

    const cancelarBorrado = () => {
        modalBorrado.value = false;
        propuestaABorrar.value = null;
    };

    const ejecutarBorrado = () => {
        if (!propuestaABorrar.value) return;
        borrando.value = true;
        router.delete(route('admin.agenda.destroy', propuestaABorrar.value.id), {
            onSuccess: () => {
                modalBorrado.value = false;
                propuestaABorrar.value = null;
                borrando.value = false;
            },
            onError: () => {
                borrando.value = false;
            },
        });
    };

NOTA: Si en el Index.vue la variable que itera se llama distinto a "propuesta"
(por ejemplo "item", "agenda", etc.), ajusta los nombres en el template.
Busca el v-for para saber el nombre exacto de la variable.

    <script setup>
    import AdminLayout from '@/Layouts/AdminLayout.vue';
    import { Head, Link } from '@inertiajs/vue3';

    const props = defineProps({
        propuesta:        Object,
        citasConfirmadas: Array,
    });

    const nombreComprador = props.propuesta.comprador?.nombre_empresa
                         ?? props.propuesta.comprador?.name
                         ?? 'Sin nombre';

    const estadoConfig = {
        pendiente: { label: 'Pendiente',  color: 'bg-yellow-100 text-yellow-700 border-yellow-200' },
        aceptada:  { label: 'Aceptada',   color: 'bg-green-100 text-green-700 border-green-200'  },
        rechazada: { label: 'Rechazada',  color: 'bg-red-100 text-red-700 border-red-200'        },
    };

    const cfg = estadoConfig[props.propuesta.estado] ?? estadoConfig.pendiente;

    const formatFecha = (f) => f
        ? new Date(f).toLocaleString('es-MX', {
            day: '2-digit', month: 'short', year: 'numeric',
            hour: '2-digit', minute: '2-digit'
          })
        : '—';

    const formatHora = (f) => f
        ? new Date(f).toLocaleTimeString('es-MX', { hour: '2-digit', minute: '2-digit' })
        : '—';
    </script>

    <template>
        <AdminLayout>
            <Head :title="`Agenda — ${nombreComprador}`" />

            <div class="max-w-3xl mx-auto py-8 px-4">

                        <h1 class="text-xl font-black text-guinda-800 dark:text-white">
                            Propuesta de agenda
                        </h1>
                        <p class="text-sm text-gray-500 mt-0.5">
                            {{ propuesta.evento?.nombre ?? 'Evento' }}
                        </p>
                    </div>

                        class="text-sm text-gray-500 hover:text-guinda-700 transition-colors">
                        ← Volver
                    </Link>
                </div>

                <!-- Tarjeta de resumen -->
                <div class="bg-white dark:bg-gray-800 rounded-2xl shadow border
                            border-gray-100 dark:border-gray-700 p-5 mb-5">
                    <div class="flex items-start justify-between gap-4">
                        <div>
                            <p class="text-xs text-gray-400 uppercase tracking-wide font-bold mb-0.5">
                                Comprador
                            </p>
                            <p class="text-base font-black text-gray-900 dark:text-white">
                                {{ nombreComprador }}
                            </p>
                            <p class="text-sm text-gray-500">
                                {{ propuesta.comprador?.email }}
                            </p>
                        </div>
                        <span :class="['text-xs font-bold px-3 py-1.5 rounded-full border', cfg.color]">
                            {{ cfg.label }}
                        </span>
                    </div>

                    <div class="grid grid-cols-2 gap-4 mt-4 pt-4
                                border-t border-gray-100 dark:border-gray-700">
                        <div>
                            <p class="text-xs text-gray-400 uppercase tracking-wide font-bold mb-0.5">
                                Enviada
                            </p>
                            <p class="text-sm text-gray-700 dark:text-gray-300">
                                {{ formatFecha(propuesta.created_at) }}
                            </p>
                        </div>
                        <div>
                            <p class="text-xs text-gray-400 uppercase tracking-wide font-bold mb-0.5">
                                Respondida
                            </p>
                            <p class="text-sm text-gray-700 dark:text-gray-300">
                                {{ formatFecha(propuesta.respondida_at) }}
                            </p>
                        </div>
                    </div>
                </div>

                <!-- Citas propuestas -->
                <div class="bg-white dark:bg-gray-800 rounded-2xl shadow border
                            border-gray-100 dark:border-gray-700 overflow-hidden mb-5">
                    <div class="px-5 py-3 bg-gray-50 dark:bg-gray-700/50
                                border-b border-gray-100 dark:border-gray-700">

                            Citas propuestas ({{ propuesta.citas?.length ?? 0 }})

                                    class="w-8 h-8 rounded-full object-cover border

                                    class="w-8 h-8 rounded-full bg-guinda-100 flex items-center

                                    <span class="text-guinda-700 text-xs font-bold">
                                        {{ (cita.restaurantero?.nombre ?? '?')[0] }}
                                    </span>
                                </div>
                                <span class="text-sm font-semibold text-gray-800 dark:text-gray-200">
                                    {{ cita.restaurantero?.nombre ?? '—' }}
                                </span>

                                         dark:bg-gray-700 dark:text-gray-400
                                         px-2.5 py-1 rounded-full">
                                {{ formatHora(cita.slot_inicio) }} – {{ formatHora(cita.slot_fin) }}

                    </div>

                <!-- Citas confirmadas (solo si fue aceptada) -->
                <div v-if="propuesta.estado === 'aceptada' && citasConfirmadas?.length"

                    <div class="px-5 py-3 bg-green-50 dark:bg-green-900/20
                                border-b border-green-100 dark:border-green-800">
                        <h2 class="text-sm font-black text-green-700 dark:text-green-400
                                   uppercase tracking-wide">
                            ✅ Citas confirmadas en sistema ({{ citasConfirmadas.length }})
                        </h2>
                    </div>
                    <div v-for="cita in citasConfirmadas" :key="cita.id"
                        class="flex items-center justify-between px-5 py-3
                               border-b border-green-50 dark:border-green-900/20 last:border-0">
                        <span class="text-sm font-semibold text-gray-800 dark:text-gray-200">
                            {{ cita.restaurantero?.nombre ?? '—' }}
                        </span>
                        <span class="text-xs font-bold text-green-700 bg-green-100
                                     dark:bg-green-900/30 dark:text-green-400
                                     px-2.5 py-1 rounded-full">
                            {{ formatHora(cita.inicio) }} – {{ formatHora(cita.fin) }}
                        </span>
                    </div>
                </div>

                <!-- Acciones -->
                <div class="flex justify-end gap-3">
                    <Link :href="route('admin.agenda.index')"
                        class="px-4 py-2 text-sm font-semibold text-gray-600
                               hover:text-gray-800 transition-colors">
                        ← Volver a la lista
                    </Link>
                </div>

            </div>
        </AdminLayout>
    </template>

VERIFICACIÓN
════════════════════════════════════════════════════════════════════════════════

1. BOTÓN VER:
   a) Ve a Admin → Agenda
   b) Haz clic en "👁 Ver" en cualquier propuesta
   c) Verifica que abre la vista de detalle con:
      - Nombre del comprador, email, fecha enviada, fecha respondida, estado
      - Lista de citas propuestas con nombre del proveedor y horario
      - Si está aceptada: también muestra las citas confirmadas en verde

2. BOTÓN BORRAR — propuesta pendiente:
   a) Haz clic en "🗑 Borrar" en una propuesta pendiente
   b) Verifica que aparece el modal con el nombre del comprador
   c) Haz clic en "Sí, borrar todo"
   d) Verifica que regresa a la lista con "✅ Propuesta eliminada correctamente."
   e) Verifica en BD: la propuesta ya no existe en agendas_propuestas
   f) Verifica en BD: las citas de agenda_propuesta_citas también se borraron

3. BOTÓN BORRAR — propuesta aceptada:
   a) Haz clic en "🗑 Borrar" en una propuesta con estado "Aceptada"
   b) El modal debe mostrar la advertencia en rojo:
      "⚠️ Esta propuesta fue aceptada — también se borrarán las citas confirmadas del comprador."
   c) Haz clic en "Sí, borrar todo"
   d) Verifica en BD que también se eliminaron las citas de la tabla `citas`

4. BOTÓN CANCELAR:
   a) Abre el modal de borrado
   b) Haz clic en "Cancelar"
   c) El modal debe cerrarse sin borrar nada
