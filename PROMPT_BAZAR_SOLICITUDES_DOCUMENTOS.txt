PROMPT: BAZAR – SOLICITUDES + DOCUMENTOS (INE/CSF)
=====================================================
Plataforma: Laravel 11 + Inertia.js + Vue 3 + Tailwind CSS (darkMode:'class', guinda #8B1028)
Producción: impulsate.iyemyucatan.com

CONTEXTO
--------
El módulo de Bazar/Exposición usa tipo='expositor' en la tabla evento_usuario.
Hay 5 problemas que resolver:

1. La página Admin/Eventos/Solicitudes.vue solo filtra por tipo='proveedor' y tipo='comprador',
   entonces las solicitudes de expositores existen en BD (se ven en el contador) pero NUNCA
   se muestran como tarjetas.

2. Antes de que un usuario pueda registrarse al bazar, se debe exigir que suba su INE y su
   Constancia de Situación Fiscal (CSF) con fecha no mayor a 3 meses.

3. Los documentos se guardan en el perfil del usuario (campos ine_path, csf_path, csf_fecha).

4. El administrador debe poder ver esos documentos en el modal de perfil de la solicitud.

5. Para eventos tipo='bazar_exposicion', la sección de "Agregar proveedor/comprador" no debe
   mostrarse.

Cada cambio está numerado. Aplícalos en orden.

CAMBIO 4 – Método subirDocumentos en CompletarPerfilController

    public function subirDocumentos(Request $request)
    {
        $request->validate([
            'ine'      => 'nullable|file|mimes:pdf,jpg,jpeg,png|max:5120',
            'csf'      => 'nullable|file|mimes:pdf,jpg,jpeg,png|max:5120',
            'csf_fecha'=> 'nullable|date|before_or_equal:today',
        ], [
            'ine.max'       => 'El INE no debe pesar más de 5 MB.',
            'csf.max'       => 'La CSF no debe pesar más de 5 MB.',
            'csf_fecha.before_or_equal' => 'La fecha de la CSF no puede ser futura.',
        ]);

        $user = $request->user();
        $datos = [];

        if ($request->hasFile('ine')) {
            // Borrar archivo anterior si existe
            if ($user->ine_path && \Storage::disk('public')->exists($user->ine_path)) {
                \Storage::disk('public')->delete($user->ine_path);
            }
            $datos['ine_path'] = $request->file('ine')
                ->storeAs("documentos/{$user->id}", 'ine.' . $request->file('ine')->extension(), 'public');
        }

        if ($request->hasFile('csf')) {
            if ($user->csf_path && \Storage::disk('public')->exists($user->csf_path)) {
                \Storage::disk('public')->delete($user->csf_path);
            }
            $datos['csf_path'] = $request->file('csf')
                ->storeAs("documentos/{$user->id}", 'csf.' . $request->file('csf')->extension(), 'public');
        }

        if ($request->filled('csf_fecha')) {
            $datos['csf_fecha'] = $request->csf_fecha;
        }

        if (!empty($datos)) {
            $user->update($datos);
        }

        return back()->with('documentos_success', 'Documentos actualizados correctamente.');
    }

    if (!fecha) return '—';

};

// CSF vigente (≤ 3 meses)

    if (!csf_fecha) return false;
    const fecha = new Date(csf_fecha);
    const limite = new Date();
    limite.setMonth(limite.getMonth() - 3);
    return fecha >= limite;
};

NOTAS FINALES

Orden de aplicación:
1. php artisan make:migration add_documentos_legales_to_users_table → editar → php artisan migrate
2. Editar User.php ($fillable)
3. Agregar ruta en web.php
4. Agregar método subirDocumentos en CompletarPerfilController.php
5. Crear DocumentosLegalesForm.vue + editar Profile/Show.vue
6. Editar EventoRegistroController.php (gate)
7. Editar EventoSolicitudesController.php (validaciones + datos)
8. Reemplazar Solicitudes.vue completo

Después de todos los cambios:
  php artisan storage:link  (si no estaba hecho)
  npm run build (producción) o npm run dev (local)

El expositor rechazado puede re-registrarse: EventoRegistroController::registrarBazar()
ya lo maneja (actualiza estado a 'pendiente' si el registro existía como rechazado).

Para el gate de documentos: si el usuario llega al modal de confirmación del bazar sin
documentos, el backend rechaza la solicitud con error y TabEventos.vue lo muestra via
el manejo de errores de Inertia (el form.errors.error).
