return Inertia::render con sin_evento=true, proveedoresPlataforma=null)

3C. Agrega este nuevo método al final de la clase (antes del cierre }):

    /**
     * Segundos restantes hasta que abra el registro de solicitudes de bazar.
     * Retorna null si ya abrió o si no hay fecha configurada.
     */
    public function segundosHastaSolicitudes(): ?int
    {
        if (!$this->fecha_aceptacion_solicitudes) return null;
        $diff = now()->diffInSeconds($this->fecha_aceptacion_solicitudes, false);
        return $diff > 0 ? $diff : null;
    }

    /**
     * ¿Está abierto el registro de solicitudes de bazar ahora mismo?
     */
    public function registroSolicitudesAbierto(): bool
    {
        if (!$this->fecha_aceptacion_solicitudes) return true; // sin fecha = siempre abierto
        return now()->gte($this->fecha_aceptacion_solicitudes);
    }

CAMBIO 9 — DEPLOY A PRODUCCIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Antes de hacer el deploy, asegúrate de tener todos los cambios
commiteados y pusheados a la rama principal (git push).

Luego conéctate al servidor por SSH y ejecuta los siguientes comandos
en orden. (Proporciona las credenciales tú mismo al conectarte — no
las escribas en ningún archivo ni se las compartas a Claude.)

Una vez dentro del servidor, navega a la carpeta del proyecto y ejecuta:

    cd /ruta/al/proyecto   # ajusta según tu servidor

    git pull origin main   # o la rama que uses

    composer install --no-dev --optimize-autoloader

    php artisan migrate --force

    php artisan config:cache
    php artisan route:cache
    php artisan view:cache
    php artisan event:cache

    npm ci
    npm run build

    php artisan storage:link   # solo si no existe ya el enlace simbólico

    php artisan queue:restart  # si tienes workers de cola activos

    # Verifica que el sitio responde correctamente:
    curl -I https://impulsate.iyemyucatan.com

Si el servidor usa Supervisor para las colas, reinicia el proceso:

    sudo supervisorctl restart laravel-worker:*

IMPORTANTE: Cambia la contraseña SSH después del deploy si aún no
lo has hecho. Nunca compartas credenciales SSH por chat.
