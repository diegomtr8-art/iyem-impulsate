2.3 — CALENDAR DINÁMICO en Restauranteros/Show.vue

  ANTES (línea 46 aprox):
    const timeSlots = ['09:00','09:30','10:00','10:30',...];  // hardcodeado cada 30min

  DESPUÉS — Generar timeSlots dinámicamente:

  const intervalo = computed(() => {
      const t = props.evento?.tiempo_entre_citas_minutos ?? 30;
      // Asegurar múltiplo de 5, mínimo 5
      return Math.max(5, Math.round(t / 5) * 5);
  });

  const timeSlots = computed(() => {
      const slots = [];
      const inicio = 9 * 60;   // 09:00 en minutos
      const fin    = 16 * 60;  // 16:00 en minutos (último inicio posible)
      const paso   = intervalo.value;
      for (let min = inicio; min < fin; min += paso) {
          const hh = String(Math.floor(min / 60)).padStart(2, '0');
          const mm = String(min % 60).padStart(2, '0');
          slots.push(`${hh}:${mm}`);
      }
      return slots;
  });

  NOTA: timeSlots era const array → ahora es computed. Actualizar todas
  las referencias a timeSlots en el template para usar timeSlots.value
  (o simplemente timeSlots si se usa en el template directamente con Vue 3).
