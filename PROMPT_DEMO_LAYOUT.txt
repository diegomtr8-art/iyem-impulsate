PROMPT PARA CLAUDE CODE - DEMO ZONA COMERCIAL YUCATÁN 200
==========================================
Proyecto base: C:\xampp\htdocs\citas (Laravel 11 + Inertia.js + Vue 3)
Páginas nuevas (sin auth, sin middleware, sin conexión a la BD):
  GET /demo-prueba/layout  → resources/js/Pages/Demo/Layout.vue
  GET /demo-prueba/paid    → resources/js/Pages/Demo/Paid.vue
Fuente tipográfica: Figtree (ya instalada en el proyecto vía bunny.net)
Color guinda IYEM: #8b1028. Fondo oscuro tipo motorsport (negro/carbono).
Esta es una DEMO de alto impacto para el evento Yucatán 200 — debe verse
PROFESIONAL, MODERNA y con una experiencia UX/UI de primer nivel.

PASO 5: DETALLES TÉCNICOS DE IMPLEMENTACIÓN
==========================================
1. Three.js: cargarlo dinámicamente en onMounted() para evitar SSR issues:
   ```js
   onMounted(async () => {
     const script = document.createElement('script');
     script.src = 'https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js';
     script.onload = () => initScene();
     document.head.appendChild(script);
   });
   ```

2. Raycasting para interacción: usar THREE.Raycaster con el array de meshes de stands.
   En cada mousemove/click, calcular intersecciones y actuar según resultado.

3. Tween suave para animaciones de stands: implementar con requestAnimationFrame y
   interpolación lineal simple (lerp). No necesita librería externa.

4. El panel lateral de detalle: es un div Vue con v-if y transición CSS (slide-in 300ms).
   No es parte del canvas 3D — es HTML sobre el canvas (position: absolute o fixed).

5. Estado reactivo: usar ref() de Vue para:
   - selectedSpace (el espacio clickeado, null si ninguno)
   - hoveredSpace (el espacio en hover, para tooltip)
   - vendidos (array, inicializado con VENDIDOS constante)

6. Guardar meshes en un Map<id, mesh> para poder actualizarlos (hover color, selected).

7. Cleanup: en onUnmounted(), llamar a renderer.dispose() y cancelar requestAnimationFrame.
